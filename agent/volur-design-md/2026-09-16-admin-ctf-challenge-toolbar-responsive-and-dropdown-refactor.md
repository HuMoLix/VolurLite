# 管理端 CTF 赛题管理工具栏“更多操作”收敛与移动端响应式重构

## 1. 变更背景与需求溯源

在 [`src/volur-lite-view/src/views/admin/challenge/AdminCtfChallengeView.vue`](file:///Users/humolix/Documents/Dev/Volur-Lite/src/volur-lite-view/src/views/admin/challenge/AdminCtfChallengeView.vue) 中：
- **桌面端空间拥挤与换行痛点**：在 100% 缩放比例下（特别是在 1080P 分辨率且系统推荐缩放 125%/150%、或 1366x768 / 1440x900 的笔记本屏幕上），左侧搜索筛选区与右侧平铺的 4 个操作按钮（“新增题目”、“导入题目 (ZIP)”、“导出全部”、“分类管理”）合计所需最小宽度达 1163px。当可用宽度不足时，右侧按钮组被迫折行到第二行，造成搜索栏与按钮割裂；缩小至 90% 时逻辑宽度放大，才勉强回归单行。
- **移动端与小屏触控不友好**：固定像素宽度导致在手机屏（$\le 768\text{px}$）上元素被截断、按钮排列混乱，缺乏专为移动端单手触控优化的弹性流式布局。

开发者决定采用 **方案 B（主要操作平铺 + 次要/批处理操作收敛至下拉菜单）配合 方案 C（移动端响应式流式布局与媒体查询适配）**，先行在 `AdminCtfChallengeView.vue` 进行重构验证。

---

## 2. 详细改造方案与实现

### 2.1 右侧次要操作收敛为“更多操作”下拉菜单 (方案 B)
1. **保留核心主操作暴露**：
   - 核心 CTA 保持为高亮独立按钮：`[新增题目]`（纯黑背景、纯白文字、圆角 8px）。
2. **通过 `<n-dropdown>` 统一收纳数据维护与配置动作**：
   - 将“导入题目 (ZIP)”、“导出全部 / 导出所选 (x)”、“分类管理”整合至“更多操作”下拉菜单；
   - 选中行时动态提供“导出所选 (x)”与“导出全部题目”双重粒度；
   - 按钮组右侧总宽度由原先的 **521px** 锐减至约 **230px**（缩水超 55%），为左侧留出充裕呼吸空间。
3. **桌面端总占用宽度锐减**：
   - 左右两侧总宽度由 **1163px** 降至 **约 810px**；
   - 在任何主流分辨率（1280px / 1366px / 1440px / 1536px / 1920px）的 100% 缩放比例下，均能稳定保持在一行内，彻底消除溢出换行。

### 2.2 左侧输入控件与分类选择轻度紧凑化
- `n-select`（分类）：由 `170px` 调整为 `150px`，保持分类名称与图标清晰展示的前提下更紧凑；
- `n-input`（搜索名称）：宽度调整为 `220px`（最小 `160px`），兼顾关键字输入与紧凑度。

### 2.3 移动端响应式与视口自适应重构 (方案 C)
新增 `@media (max-width: 768px)` 媒体查询专属规则：
1. **容器流式分层**：
   - `.filter-header` 在移动端改为纵向 `flex-direction: column; align-items: stretch;`；
   - 左侧分类下拉框与搜索框在手机端自动撑满 100% 宽度，文字清晰易触达。
2. **触控友好的按钮等宽排布**：
   - “搜索”与“重置”按钮在移动端并排成双等宽列（各占 50%，`flex: 1`），防止手滑误触；
   - “新增题目”与“更多操作”按钮在移动端同样并排成双等宽列（各占 50%），符合单手拇指操作习惯；
   - 下拉菜单设置 `placement="bottom-end"`，在手机窄屏视口内自动居右对齐安全弹出，不产生横向滚动溢出。

### 2.4 主题样式与色彩令牌规范化
- 重构 `.theme-primary-btn` 样式，引入 `var(--v-btn-primary-bg, #000000)` 与 `var(--v-btn-primary-text, #ffffff)` 及对应的 Hover/Active 令牌，确保在日间纯黑主色与黑夜模式高对比反色之间无缝自适应切换。
